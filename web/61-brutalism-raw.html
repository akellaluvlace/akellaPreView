Build for the
reader, not the
algorithm.

The web does not require ornament. It requires legibility. It requires durability. It requires that data, once written, remains both readable and trustworthy a decade from now — without a runtime, without a CDN, without an account.

We have spent twenty-five years adding chrome to a medium that was complete in 1995. MANUAL_v1 is a return to the principles that worked: hyperlinks. Plain text. Headings, paragraphs, tables. The browser as document reader. Anything more is an error introduced by us, not corrected by us.

Five Tenets
  1. 01

    No JavaScript.

    If a feature requires JS to be readable, it is not a feature. It is a regression.

  2. 02

    No Cookies.

    Reading should not require an exchange of identity. The reader is anonymous, by default.

  3. 03

    No Tracking.

    We do not measure what we do not need to know. The server log records 200s and 404s. Nothing more.

  4. 04

    Print Tested.

    Every page renders cleanly on A4 / Letter. The web should also live on paper.

  5. 05

    Public Domain by Default.

    Documentation belongs to the people who read and write it. Not to a vendor.

"If you cannot view this in lynx, we have failed."
