// CODICIL · ROMANUS

Five laws
of alchemy.

Pinned above the kettle since 1954. Bent twice, broken thrice, restated for the new bench. Memorise them or laminate them, but don't ignore them.

  1. I

    Begin where the dust collects.

    A spotless bench yields nothing. Find the corner the apprentice forgot to sweep. That is the substrate.

    [ LEX_01 ]
  2. II

    Halftone is honesty.

    The pixel hides nothing. The dot lies less. When in doubt, scale up the screen and let the audience read the texture.

    [ LEX_02 ]
  3. III

    A red shadow is a promise.

    Drop the eight-pixel offset and the page reads as flat. Keep it; the page reads as sworn. Pop is a covenant.

    [ LEX_03 ]
  4. IV

    The knob remembers.

    Whatever you set yesterday is still set today. Re-zero before you crank. The bench rewards memory and punishes the optimistic.

    [ LEX_04 ]
  5. V

    Stamp the work, leave the room.

    Every folio gets one stamp and one signature. Don't return to retouch. The page closes when the press closes.

    [ LEX_05 ]

01

Does the matrix actually transmute, or is it just a printer?

add
It transmutes. The print head is decorative. Every fragment in returns at 0.41 oz of usable yield, plus or minus what you forget to clean off the rollers.
02

Can I run two fragments in parallel?

add
Yes, if your bench is grade-B or higher. The kettle holds three; the calibration wheel holds two. The third one waits in the rack and gets a halftone tan.
03

What if my fragment is corrupted?

add
Corruption is a feature. The terminal logs the breach as [ANOMALY · KEEP] and routes it to the gallery wall. Critics call this our most honest output.
04

Why are there four screws on every panel?

add
Three would suggest hesitation. Five would suggest neurosis. Four screws says: this panel was meant to be opened, but rarely.
05

Is the warning at the bottom serious?

add
Catastrophically. Once the big red button is hit the matrix consumes the source fragment, the operator's previous lunch, and any unsaved drafts opened on the same network. Print twice. Save once.
