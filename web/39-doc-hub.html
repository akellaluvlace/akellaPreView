Getting Started with Palette API

Welcome to the Palette API. We provide a comprehensive color-system-as-a-service, allowing developers to programmatically generate, manage, and distribute accessible color palettes across web, mobile, and print applications. Start integrating dynamic themes into your product in minutes.

Quickstart

To interact with the API, you'll need an API key. You can create one in your dashboard after signing up. Below is a simple request to generate a complementary color palette based on a primary brand hex code. 

curl -X POST https://api.palette.dev/v1/generate \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "base_color": "#6C5CE7",
    "strategy": "complementary",
    "steps": 5
  }'

From brand colour to production palette

Three stages, from a designer pasting one hex code into the dashboard to a production CDN serving the resulting tokens to thousands of clients.

— input

Drop a hex, pick a strategy

Designers paste one brand colour into the dashboard and choose a generation strategy — analogous, complementary, monochrome, split-complementary, or seeded from an uploaded image. Engineers can do the same with a single POST.

  • check_circle1 brand hex → 5 / 7 / 11 token steps

— compile

Tokens, contrast-checked

Each generated palette is graded against WCAG, scored for perceptual evenness in OKLCH, and emitted as design tokens. Same source of truth, every platform.

CSS variables Tailwind config JSON tokens iOS asset catalog Android colors.xml
— distribute

Versioned, cached, webhooked

Every palette gets a stable version slug, edge-cached at 214 PoPs, and emits a webhook on rotation so design systems and Storybook builds rebuild automatically. No manual export.

/ faq

Common questions

Is generation deterministic?

chevron_right

Yes. Same brand hex + same strategy + same seed always produces the same palette. Useful for reproducible builds and for diffing two palettes during a brand refresh.

What happens to existing tokens when a palette rotates?

chevron_right

Each rotation produces a new immutable version slug; the old slug stays cacheable for 24 hours, then 410s. Webhooks fire on rotation so consumers can rebuild Storybook / asset catalogs automatically.

Do you store our brand colours?

chevron_right

Only as input + your generated palettes, scoped to your workspace. There's a stateless mode (X-Palette-Stateless: true) that returns the palette without persisting anything.

How do contrast locks interact with strategies?

chevron_right

A lock declares minimum required contrast between named tokens (e.g., on-primary ≥ 4.5 against primary). The generator nudges hue + lightness within the strategy's family until the lock is satisfied. If it can't, the response includes a contrast_warning array instead of failing.

Are SDKs available?

chevron_right

Official: TypeScript, Python, Ruby, Go, Swift. Community-maintained: Rust, Elixir, .NET. The REST API is stable enough that any HTTP client works fine if your stack isn't on the list.
