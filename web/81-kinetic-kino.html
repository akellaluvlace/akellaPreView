06 / DOCTRINE

Five rules
the foundry runs on.

Etched on the studio door in 2014. Bent twice. Broken thrice. Re-stencilled every ten years.

Read the manual →
  1. I

    A typeface is software, not jewellery.

    Ship the variable file, not the licence call. The stylist comes second; the engineer comes first.

    [ TENET_01 ]
  2. II

    Draw the axis before the alphabet.

    Decide what changes — width, slant, contrast — before you draw the A. The whole family follows the axis, not the other way around.

    [ TENET_02 ]
  3. III

    Italics earn their slant.

    Auto-italics are an insult. Each italic glyph gets drawn from scratch — or you don't ship the italic.

    [ TENET_03 ]
  4. IV

    If it doesn't load fast, it doesn't ship.

    The file is opened more often than it is read. Strip everything that doesn't serve the eye on a 3G connection.

    [ TENET_04 ]
  5. V

    License once. Update forever.

    A buyer pays once for a font. The foundry repays them with five years of bug fixes and the next axis on the house.

    [ TENET_05 ]

Four standing terms.

I
Compact · 01

One file, every axis.

A single .woff2 contains weight, width, optical-size and slant — no per-weight licence calls, no fallback fonts. The studio panel slices static cuts on demand, free.

≤ 80 KB · all axes [ ARMED ]
II
Compact · 02

Italics drawn, not slanted.

Each italic glyph is hand-drawn from scratch — no auto-skew, no fake oblique. If a face doesn't earn its italic, we don't ship one until the next axis cuts.

07 / SUPPORT

Pre-licence questions.

Asked by sixty-three studios this quarter. Answered by the foundry, in five lines or fewer.

01

Is the variable file the only file you ship?

+

Yes. One .woff2, every axis. The static cuts are sliced from the variable on demand if a buyer needs them — but the licence covers the whole space.

02

Can I license for a single project?

+

Always. One-shot licences live in the studio panel; perpetual licences live in the foundry. Both ship within the hour, both come with the five-year update guarantee.

03

What about variable in print?

+

Adobe and Affinity both speak the variable axis as of 2024. We ship a `.glyphs` source plus the `.woff2`; print desks pick the slice they want, foundry signs the slice.

04

Do you do bespoke?

+

Three commissions a year, six months minimum. Conversations begin with a single page of brief; the first axis cuts in week six.

05

Why no decoration on the page?

+

The typography is the decoration. Anything else competes with the specimen.
