// DOCTRINE — V.05 // NON_NEGOTIABLE

HOW I WORK

Five rules I've broken every other one to keep. Print these. Pin them above the keyboard. Argue with them later.

[studio_floor / 06.24] DOC.05
▸ MANIFESTO
  1. 01

    BRIEFS ARE A SKETCH, NOT A SPEC

    If the brief solves the problem already, you didn't need me. Every project starts with a fight, ends with a thing that nobody could have written down up front.

  2. 02

    SHIP THE UGLY VERSION FIRST

    Day-one demos are HTML and pure CSS. No Figma comp, no design system, no "let's prototype it." If it doesn't survive a 256-colour render, it isn't going in.

  3. 03

    NO ANIMATIONS WITHOUT A REASON

    Motion costs money — yours, the user's, the planet's. Every transition either teaches the interface or pays its own rent. The rest get cut.

  4. 04

    NEVER TWO ROUNDS OF "POLISH"

    Polish-passes are where good work goes to die a polite death. One pass to fix the brief, one pass to break it on purpose. The third pass is bikeshedding wearing a costume.

  5. 05

    THE WORK OUTLASTS THE BRIEF

    If you can't print it on a poster five years from now, it isn't worth shipping today. Build for the archive, not the algorithm.

verified
